Arquitectura y Flujo del Sistema

Estructura del backend, lógica de acceso y procesamiento de IA

1. Ciclo de Pago y Activación de Cuenta

01
Generación de Licencia

El administrador genera una clave única desde el panel de control. El sistema reserva el código en la base de datos con estado pending.

Supabase PostgreSQL
02
Canje de Código

El usuario ingresa su código. El sistema verifica la validez, marca el código como used y lo vincula al número de teléfono del usuario.

Node.js REST API

2. Validación de Acceso y Respuesta de IA

03
Control de Acceso

Antes de cada interacción, el sistema valida que subscription_active sea verdadero y que la fecha de expiración sea futura. Sin acceso, no hay procesamiento.

Auth Service Real-time Check
04
Procesamiento de IA

Una vez validado el acceso, el mensaje se envía a la IA. Se extrae el contexto, se analizan transacciones y se genera una respuesta personalizada enviada vía WhatsApp.

OpenAI / Groq WhatsApp Cloud API

Resumen del Flujo Completo

El sistema garantiza que el valor de la IA sea exclusivo para usuarios activos. El flujo Pago → Acceso → IA → Respuesta está blindado por validaciones en cada paso, asegurando que solo las cuentas habilitadas consuman recursos de procesamiento de lenguaje natural.
